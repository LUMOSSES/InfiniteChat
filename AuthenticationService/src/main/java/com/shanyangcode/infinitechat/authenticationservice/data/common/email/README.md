# data.common.email 包说明

## 包职责
定义“邮箱验证码发送”接口的请求与响应模型。

## 为什么创建这个包
从需求上看，验证码发送是一个独立 API：
- 输入：邮箱地址
- 输出：确认已发送到哪个邮箱

把这组 DTO 独立出来，能避免与登录/注册 DTO 混淆。

## 类说明
### `EmailRequest`
- 字段：`email`
- 校验：非空 + 邮箱格式
- 作用：约束接口输入，防止无效邮箱进入业务层。

### `EmailResponse`
- 字段：`email`
- 作用：回显目标邮箱，帮助前端确认发送目标。

## 开发时思考过程
1. 先定义请求约束，确保“脏请求”尽早被拦截。
2. 响应模型只返回前端必要信息，不暴露内部实现细节。
