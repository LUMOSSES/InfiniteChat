# utils 包说明

## 包职责
放置可复用工具能力，避免业务层重复造轮子。

## 为什么创建这个包
需求实现中会出现大量“与业务强相关但可复用”的小能力：
- JWT 生成/解析
- 验证码生成
- 昵称生成
- 邮件发送
- MinIO URL 生成

这些能力如果散落在 service，会导致代码臃肿且难复用。

## 类说明
### `JwtUtil`
- JWT 生成与解析工具。
- 服务中用于登录发 token、接口解析 token。

### `EmailUtil`
- 基于 `JavaMailSender` 发送验证码邮件。
- 将邮件模板和发送细节与业务逻辑分离。

### `OSSUtils`
- 生成 MinIO 预签名上传 URL 与下载 URL。
- 把对象存储 SDK 细节封装起来。

### `RandomNumUtil`
- 生成 6 位随机验证码。

### `NickNameGeneratorUtil`
- 为新注册用户生成默认昵称。

## 开发时思考过程
1. 识别“可复用且与领域逻辑弱耦合”的代码片段。
2. 提取为工具类并保持单一职责。
3. 让 service 只编排业务，不处理底层细节。
