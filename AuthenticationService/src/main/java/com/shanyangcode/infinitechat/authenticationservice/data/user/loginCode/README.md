# data.user.loginCode 包说明

## 包职责
定义“邮箱验证码登录”接口 DTO。

## 为什么要创建这个包
验证码登录是密码登录的替代路径，字段不同且风控策略不同。  
独立建包可以让两条登录链路互不干扰，便于灰度和策略演进。

## 类说明
### `LoginCodeRequest`
- 字段：`email`、`code`
- 校验：
  - 邮箱非空 + 格式合法
  - 验证码非空 + 6 位长度约束
- 作用：描述验证码登录请求并做输入约束。

### `LoginCodeResponse`
- 字段与 `LoginResponse` 基本一致：用户摘要 + `token`
- 作用：保证前端在两种登录方式下拿到统一会话信息结构。

## 模拟开发思路
1. 产品要求“免密码登录”时，先定义验证码登录协议。
2. 请求里强调验证码字段，响应保持和密码登录尽量一致。
3. 这样前端登录成功后的状态处理逻辑可以复用。
