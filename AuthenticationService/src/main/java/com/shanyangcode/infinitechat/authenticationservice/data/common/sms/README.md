# data.common.sms 包说明

## 包职责
定义短信验证码相关 DTO（当前项目中为能力预留）。

## 为什么创建这个包
需求上通常邮箱验证码和短信验证码会并存。  
提前做结构隔离，可以让后续接入短信渠道时不需要重构 DTO 目录。

## 类说明
### `SMSRequest`
- 字段：`phone`
- 校验：非空 + 长度校验
- 作用：描述短信验证码发送请求体。

### `SMSResponse`
- 字段：`phone`
- 作用：确认短信发送目标。

## 开发时思考过程
1. 先定义协议层对象，为未来短信能力预留扩展位。
2. 即使暂未全量启用，也保持模型边界完整。
