# data.user.updateAvatar 包说明

## 包职责
定义“更新头像”接口 DTO。

## 为什么要创建这个包
头像更新是一个独立用户动作，入参与注册/登录完全不同。  
单独建包可以把“资源地址更新”从“身份登录流程”中分离，降低耦合。

## 类说明
### `UpdateAvatarRequest`
- 字段：`avatarUrl`
- 校验：非空
- 作用：接收新的头像地址。
- 设计提示：当前字段是 `public`，工程化上更推荐 `private + getter/setter` 保持一致风格。

### `UpdateAvatarResponse`
- 字段：用户资料字段快照（含 `avatar`）
- 作用：返回更新后的用户信息供前端刷新个人页状态。

## 模拟开发思路
1. 用户上传完头像后，需要一个“提交新头像地址”的接口。
2. 因为上传与更新是两步，更新接口只接收 URL，不处理文件流。
3. 更新成功后返回最新用户信息，减少前端额外查询次数。
