# data.common 包说明

## 包职责
承载“跨用户主流程可复用”的通用接口 DTO。

## 为什么创建这个包
需求里有一些能力属于“用户系统通用能力”，例如验证码发送、上传地址获取。  
它们与“登录注册”不是同一条业务主线，但同属认证服务，适合独立分组。

## 子包说明
- `email`：邮箱验证码发送 DTO
- `sms`：短信验证码 DTO（当前接口路径已预留）
- `uploadUrl`：对象存储上传/下载地址 DTO

## 开发时思考过程
1. 先识别通用能力是否可复用。
2. 对可复用能力单独建子包，减少 user 包复杂度。
3. 每个通用能力单独定义请求/响应模型。
