# data.user.login 包说明

## 包职责
定义“账号密码登录”接口的请求和响应对象。

## 为什么要创建这个包
登录是高频核心接口，协议必须稳定且清晰。  
把登录 DTO 单独放包里，能明确边界并避免和注册/验证码登录字段混淆。

## 类说明
### `LoginRequest`
- 字段：`email`、`password`
- 校验：
  - 邮箱非空 + 格式合法
  - 密码非空 + 长度 6-16
- 作用：在进入业务层前完成基础输入校验。

### `LoginResponse`
- 字段：`userId/userName/avatar/signature/gender/status/token`
- 作用：返回登录后客户端立即需要的会话与用户摘要信息。
- 设计思考：不返回密码等敏感字段，只返回必要展示和鉴权数据。

## 模拟开发思路
1. 从前端登录页反推请求参数最小集。
2. 先定义 `LoginRequest` 及校验注解。
3. 再定义 `LoginResponse`，只保留“登录后立即使用”的信息。
