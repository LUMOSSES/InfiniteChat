# common 包说明

## 包职责
提供全服务统一的返回体模型，确保所有接口输出结构一致。

## 为什么创建这个包
需求上，前端不希望每个接口返回格式都不同。  
统一返回体可以解决：
- 成功/失败判断逻辑统一
- 错误码体系统一
- 网关与客户端日志更容易检索

## 类说明
### `Result<T>`
- 作用：标准响应包装对象，字段为 `code/msg/data`。
- 关键能力：
  - `OK`：成功返回
  - `ValidError`：参数校验失败
  - `DatabaseError`：数据库异常
  - `ServerError`：系统异常
  - `UserError`：业务异常（可传业务码）
- 设计思考：把常见返回场景做成静态工厂，减少 Controller 重复代码和返回格式漂移。

## 开发时思考过程
1. 先定义统一响应协议。
2. 再在异常处理器中全部返回 `Result`。
3. 最后 Controller 全部使用 `Result`，避免裸对象返回。
