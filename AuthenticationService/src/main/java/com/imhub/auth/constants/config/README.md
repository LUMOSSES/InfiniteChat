# constants.config 包说明

## 包职责
管理“配置域相关常量与枚举”，服务于 token、对象存储、超时策略等基础配置。

## 为什么创建这个包
这类值在多个地方会复用，且通常较稳定。  
抽离后可以避免 service/controller 直接写硬编码，提升可维护性。

## 类说明
### `ConfigEnum`
- 当前提供 `TOKEN_SECRET_KEY`。
- 作用：JWT 签名密钥统一来源。
- 思考：密钥类常量需要集中管理，方便后续切换到配置中心或环境变量。

### `TimeOutEnum`
- 定义业务超时策略（JWT 过期时间、验证码过期时间等）。
- 思考：把时间策略参数化，避免散落在业务代码里。

### `OSSConstant`
- 定义对象存储桶名和 URL 过期时间（图片/视频/语音）。
- 思考：上传策略属于基础能力策略，不应散落在 service 中。

## 开发时思考过程
1. 先识别“配置策略”与“业务规则”的边界。
2. 将策略参数统一抽象为枚举/常量。
3. service 层只引用常量名，不关心字面值。
