# data 包说明

## 包职责
定义 API 的输入输出模型（DTO），隔离 HTTP 协议对象与数据库实体。

## 为什么创建这个包
需求上同一个业务对象在不同场景字段并不一致：  
例如“登录请求”只要邮箱和密码，而数据库 `User` 有很多字段。  
所以需要 DTO 层避免：
- 暴露敏感字段（如密码哈希）
- 请求与响应结构互相污染
- 前后端协议频繁受数据库模型变更影响

## 包内结构
- `common`：通用能力 DTO（邮箱验证码、上传 URL、短信）。
- `user`：用户身份行为 DTO（注册、登录、验证码登录、头像更新）。

## 开发时思考过程
1. 先按接口定义请求/响应字段。
2. DTO 层加校验注解（`@NotEmpty/@Email/@Length`）。
3. 在 service 中完成 DTO 与 model 的转换。
