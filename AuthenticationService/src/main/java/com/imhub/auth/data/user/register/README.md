# data.user.register 包说明

## 包职责
定义“注册”接口 DTO。

## 为什么要创建这个包
注册流程的输入和登录完全不同：注册需要验证码来证明邮箱可用。  
如果复用登录 DTO，会导致字段语义混乱，因此单独建包。

## 类说明
### `RegisterRequest`
- 字段：`email`、`password`、`code`
- 校验：
  - 邮箱非空 + 格式合法
  - 密码非空 + 长度 6-16
  - 验证码非空 + 固定 6 位
- 作用：定义注册输入并在入口层做基础校验。

### `RegisterResponse`
- 字段：`email`
- 作用：注册成功后回显账号标识（邮箱）。
- 设计思考：响应保持最小必要原则，避免过早返回多余数据。

## 模拟开发思路
1. 先定义注册必须参数：邮箱、密码、验证码。
2. 在 DTO 加注解提前拦截非法请求。
3. 注册成功返回最小确认信息，后续用户资料通过其他接口获取。
